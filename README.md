# SQL Sales Analysis Project

## Overview

This project contains 200 SQL business problems solved using:

- Joins
- Aggregate Functions
- CTEs
- Window Functions
- RANK()
- DENSE_RANK()
- NTILE()
- LAG()
- Business KPI Calculations

## Key KPIs Built

- Revenue Analysis
- Customer Lifetime Value
- Customer Retention Rate
- Return Rate
- Product Revenue Contribution
- Top Customers
- Top Categories
- Monthly Growth Analysis
- Executive Business Summary
