# E-Commerce SQL Analysis Project

## Project Overview

This project contains 200+ SQL business analysis questions solved using MySQL on an e-commerce sales dataset.

The objective was to analyze sales performance, customer behavior, product performance, retention metrics, and business KPIs commonly used in real-world analytics and reporting environments.

---

## Database Used

E-Commerce Sales Analytics Database

Main Tables:

* Customers
* Orders
* Order Details
* Products

---

## SQL Concepts Covered

* Joins (INNER JOIN, LEFT JOIN)
* Aggregate Functions
* GROUP BY & HAVING
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions

  * RANK()
  * DENSE_RANK()
  * NTILE()
  * LAG()
* Business KPI Calculations
* Customer Segmentation
* Revenue Analysis

---

## Key Business KPIs Built

* Total Revenue
* Average Order Value (AOV)
* Customer Lifetime Value (CLV)
* Customer Retention Rate
* Return Rate Analysis
* Revenue Contribution Analysis
* Monthly Revenue Trends
* Year-over-Year Growth Analysis
* Top Customers by Revenue
* Top Product Categories
* Executive Business Summary Dashboard

---

## Sample Business Questions Solved

* Find churned customers
* Identify top 20% customers by revenue
* Calculate customer retention rate
* Find fastest-growing product categories
* Determine payment mode preferences by country
* Analyze monthly revenue growth
* Calculate product revenue contribution percentages
* Build executive KPI dashboard queries
